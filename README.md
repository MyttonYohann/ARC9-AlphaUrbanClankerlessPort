
# ARC9 Urban Redevelopment

### clankerless port of the PRERELEASE/ALPHA version of the hit ArcCW mod Urban Decay.

with some minor face lifts

This will only entails Decay for the forseeable future, it is very unlikely that I'd port Renewal or even my own one offs (maybe scar).

### Changed Stuff.

**M1014**
 - New Forend slot with options to convert to a pump action
 - One new Barrel attachment, heatshield + bayonet
 - Wood options for Stock attachment
 - To not bore you with the technicallity, the transitions between reload states are MUCH smoother now
 
**Glock 17**
 - Remove Frame Attachment, G26 Frame is now tie to the 10-Round Mag
 - 'Backport' (this was unfinished lol) some of Harry's animations like bash and unjam
 - New reload anim, 33-Round and 10-Round has altered anim sets, reworked 100-Round's

**New Features**
 - Better Melee Handling
 - Extended Shotgun Handling (Uncycled and Unchambered states)
 - Animation fixes
 - Fixed up the unfinished Underbarrel RPG
 
**Remove/Altered Features**
 - Uses the old sounds rzenith made like pre covid
 - Calibre Slot is removed
 - General rules are if the Alpha/PreRelease version lack them, I'm not bothered adding, with some exceptions
 - Dragon Breath can be used on every type of shotgun but it will force the gun to be manual action (the m1014 has its own anim set !)
